# Model & Training Pipeline (Person 2 — Ximin)

Multi-output Convolutional Neural Network (CNN) baseline for SVHN multi-digit house number recognition, built with the Keras Functional API following Goodfellow et al. (2013).

---

## 1. Architecture Summary

Rather than treating every possible house number as an independent class, the network shares convolutional feature-extraction layers and branches into **$k + 1 = 6$ independent softmax heads** (`k = 5`):

* **Shared Convolutional Backbone:** Three blocks of `Conv2D` (`padding="same"`, ReLU) $\rightarrow$ `MaxPooling2D(2)` $\rightarrow$ `BatchNormalization` (filter depths: `32 -> 64 -> 128`), followed by `Flatten`, `Dense(256, relu)`, and `Dropout(0.3)`.
* **`length` Head (1 head):** `Dense(6, activation="softmax", name="length")` representing classes `0..5` (predicts digit count `1..5`; class `0` is unused so integer labels map directly to class indices).
* **`digit1` – `digit5` Heads (5 heads):** `Dense(11, activation="softmax", name="digit{i}")` representing classes `0..10`, where `0..9` correspond to digits `'0'..'9'` and `10` corresponds to `BLANK` (*"no digit in this position"*).

## 5. Hand-off Notes for Person 3 (Experiments & Evaluation)

* **Loading the Baseline Model:**
  ```python
  model = tf.keras.models.load_model("artifacts/baseline_best.keras")
  ```
* **Tunable Knobs in `CONFIG`:**
  * `conv_filters`: Increase depth/width (e.g., `[32, 64, 128, 256]`) for higher capacity.
  * `dense_units` & `dropout_rate`: Adjust shared representation capacity (`256` $\rightarrow$ `512`) and dropout (`0.3`–`0.5`).
  * `learning_rate` & Callbacks: Add `EarlyStopping(patience=4, restore_best_weights=True)` and `ReduceLROnPlateau(factor=0.5, patience=2)`.
  * **Data Augmentation:** Add Keras preprocessing layers (e.g., `RandomRotation(0.05)`, `RandomContrast(0.1)`) right after `inputs`. *Do not use horizontal flips*, as flipping changes digit identity.
* **Whole-Number Accuracy Metric:** An image is counted correct only when `pred_len == true_len` **AND** all 5 predicted digit positions match `true_digits` simultaneously (unused trailing slots are all encoded as `10`).
* **Validation Split Caveat:** `val.npz` (3,340 images) has zero 5-digit house numbers (only 9 exist in the training split), so validation accuracy reflects 1- to 4-digit numbers only.

## 6. Exam Prep & Code Walkthrough Checklist

* **Why $k + 1$ heads instead of 1 giant softmax?** Modeling a 5-digit number directly requires $10^5 = 100{,}000$ output classes, causing severe data sparsity. Factoring into 1 length head (6 classes) + 5 digit heads (11 classes each) requires only $6 + 5 \times 11 = 61$ output neurons.
* **Why `BLANK = 10` and 11 digit classes?** Raw SVHN encodes digit `'0'` as label `10`. Person 1 remapped raw `10 -> 0` so digits `'0'..'9'` align with indices `0..9`, freeing index `10` to represent `BLANK` ("no digit").
* **Why dictionary outputs & exact layer names?** `load_data.py` yields labels as `{"length": ..., "digit1": ..., ..., "digit5": ...}`. Naming the output `Dense` layers identically lets Keras match each label tensor to its head automatically.
* **Why `sparse_categorical_crossentropy`?** Labels are integer class indices (`0..5` or `0..10`) rather than one-hot encoded vectors, saving memory and avoiding manual conversion.
* **How total loss is computed:** Keras sums the 6 individual head losses ($L_{\text{total}} = L_{\text{length}} + L_{\text{digit1}} + \dots + L_{\text{digit5}}$) and backpropagates gradients jointly through the shared dense and convolutional layers.
* **How inference decoding works:** Take $\hat{L} = \arg\max(\text{preds}[\text{"length"}])$, then take $\arg\max$ of `digit1` through `digit_{L_hat}` and concatenate them (ignoring positions $> \hat{L}$).
